## 3. この案が死ぬ条件（3つ）と、いま起きているか（2026-09-28 確認）
   - 当社が必要な許可・届出を得られない
     → 古物商許可が要る形（品物を預かる・買い取る・代わりに売る）は【起きている】（制約3と同根。解けるのは期間の満了後）
     → 古物競りあっせん業の届出で足りる形（ネットで業者に競らせるだけ）は【起きていない】（届出に欠格事由の定めなし）【Gemini未確認】
   - 同じ体験を既存サービスが既に提供していて、利用者と業者が乗り換える理由を作れない
     → 【一部起きている】PREMIER VALUE が最大80社の競争入札・電話なし・AI即時査定を提供済み。残る違いは「出張で実物を1回見て、その場で一斉に入札」だけ
   - 買取業者が参加しない（お金を払ってまで個人の案件を取りに来ない）
     → 【起きていない】ヒカカク！に400社以上が成果報酬で掲載、PREMIER VALUE は80社。ただし新しい小さいサービスに参加する証拠は無い

   「出張×その場で一斉入札」が空いている理由（構造）
   - 事実：出張して自宅で買い取る業者には特定商取引法の訪問購入の規制がかかり、売り手は書面受領から8日間クーリング・オフでき、その間は品物の引き渡しを拒める（第58条の14・第58条の15）＝その場で決めても8日間は確定しない
   - 未検証：出張1回の人件費・移動費が、1件の手数料を上回る
   - 推測：写真とAIで概算が出せるようになり（PREMIER VALUE の AI即時査定 2026-03）、出張の必要性が下がっている
