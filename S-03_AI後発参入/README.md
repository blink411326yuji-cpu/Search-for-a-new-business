# S-03 AI後発参入（AIを内側に使って既存ビジネスに後発で入る新規事業）

## この置き場に入れるもの
- AIで後発参入できる既存ビジネスの調査報告・案カタログ（人が読むHTML）
- 選んだ案の仮説シート `KASETSU.md`（venture-hypothesis の型。案ごとに1枚）
- Gemini クロスレビューの記録 `GEMINI_REVIEW_*.md`

## 入れないもの
- 売却型の資料 → `../S-01_スケール売却型/`
- 店舗・地域密着型の単独調査 → `../S-02_地域密着型/`（本テーマの「地方の店舗型」の検証は報告書 第4-4節と台帳 型E に含めた）

## 命名
`_S-03_<内容>_YYYY-MM-DD.html`。旧版は消さず残置し、最新版だけをこの README から参照する。
貼り付け用の文面は `_貼り付け用_` で始める（引き継ぎ時に `_to_delete\` へ移す対象）。
